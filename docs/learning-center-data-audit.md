# 学习中心题单数据审计

> 本文档记录“信奥题单（持续更新）”向学习中心转换前的第一轮只读审计结果。它是转换依据，不代表已经开始修改题单源文件。

## 当前结论

这份工作簿不能按普通题目列表直接导入。它同时包含：

- 竞赛阶段：CSP-J、CSP-S/NOIP、省选/NOI；
- 训练位置：题单表头中的 T2、T3、T4、T5、T6、T7；
- 知识体系：基础算法、数据结构、图论、树论、动态规划、数学、字符串等；
- 课程路线：从基础阶段到高级专题的阶段性安排；
- 题目来源：洛谷题号、B 题号、Codeforces 映射题号、AtCoder 等；
- 颜色、合并单元格、横向并列专题、备注和特殊节点。

因此网站数据必须至少分开保存“教学阶段”“训练位置”“原表颜色语义”和“洛谷官方难度”四套信息。

## 工作表用途

| 工作表 | 网站用途 | 处理原则 |
|---|---|---|
| 总表介绍 | 作为内部资料和内容来源说明 | 不自动公开导入，其中可能含运营、社群和个人信息 |
| CSP-J | CSP-J 题单 | 保留专题、T2/T3/T4、题目顺序和原表颜色 |
| CSP-S+NOIP | 提高组和 NOIP 题单 | 保留图论、树论、数据结构、DP、数学等并列专题结构 |
| NOI | 省选/NOI 高级题单 | 保留高级专题、题号来源和训练层次 |
| 信奥知识点 | 学习地图和知识文档目录 | 将组别颜色转换为阶段标签与节点属性 |
| 课程表参考 | 推荐学习路线 | 转换为阶段、周次、前置关系和推荐顺序 |
| 教学经验分享 | 博客和说明内容候选来源 | 人工筛选后发布，不自动全量公开 |

## 已确认的颜色语义

颜色在不同工作表中承担不同作用，不能全局复用为一个字段。

### 题单表头中的训练位置

题单表头使用颜色区分 T2、T3、T4、T5、T6、T7 等训练位置。它表达的是题目在训练序列中的位置或层级，不等同于洛谷难度。

网站字段建议：

```text
training_position: T2 | T3 | T4 | T5 | T6 | T7
training_color_source: 原表颜色
```

### 知识点表中的竞赛阶段

“信奥知识点”中使用颜色和列标题区分 J 组、S 组+NOIP、以及省选/NOI 方向。它表达知识点适用的教学阶段，不等同于单道题的难度。

网站字段建议：

```text
stage: CSP-J | CSP-S-NOIP | PROVINCIAL-NOI
stage_color_source: 原表颜色
```

### 洛谷官方难度

洛谷难度单独同步保存：

```text
luogu_difficulty: 入门 | 普及- | 普及 | 普及+/提高- | 提高 | 提高+/省选- | 省选/NOI- | NOI/NOI+/CTS
luogu_color: red | orange | yellow | green | cyan | blue | purple | black
```

## 建议的数据关系

```text
学习阶段
  └─ 知识领域
      └─ 知识点
          ├─ 学习文档
          ├─ 题单专题
          │   └─ 题目
          │       ├─ 洛谷题面
          │       ├─ 洛谷名称与难度
          │       └─ 本站题解
          └─ 前置或关联知识点
```

同一题可以出现在多个专题中，因此题目和专题之间应使用多对多关系，不能把题目永久复制到单一目录。

## 题目标准字段

## 下一步验收样板

先选择“模拟—二维数组模拟”或同等规模的一个完整专题，做出网页样板并核对：

1. 原表专题名称是否准确；
2. 题目顺序是否保留；
3. T2～T7 是否显示为训练位置；
4. J/S/NOIP/NOI 是否显示为教学阶段；
5. 原表颜色是否仍能表达原来的含义；
6. 洛谷题目名称和难度是否单独显示；
7. 有题解、多个题解、暂无题解三种状态是否正确；
8. 题号能否跳转到正确的外部题面。

样板经确认后，再批量转换全部题单，避免早期误读导致大规模返工。
