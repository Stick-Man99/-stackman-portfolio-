学生投稿 Markdown 写作示例

掌握几个常用语法，就能把题解写得清楚又好看

投稿指南2026-09-10

Markdown 是一种简单的文章排版方式。你不需要学习复杂的网页代码，只要在投稿框里输入几个符号，就可以生成清晰的标题、列表、链接和代码。

1. 标题

在文字前面加井号。井号越少，标题层级越高：

# 一级标题
## 二级标题
### 三级标题

2. 列表

每一行用短横线开头，就可以写出列表：

- 先读题，明确输入和输出
- 再分析样例和边界情况
- 最后写代码并测试
  • 先读题，明确输入和输出
  • 再分析样例和边界情况
  • 最后写代码并测试

3. 链接

链接格式是：[链接文字](网页地址)。例如：打开洛谷。

4. 代码块

在代码前后各写一行三个反引号，并可以标注语言名称：

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    cout << "Hello, algorithm!";
    return 0;
}
```

5. 一篇完整题解可以这样组织

  1. 题目思路：你是怎么想到这个方法的？
  2. 算法步骤：把解题过程分成几步。
  3. 复杂度分析：说明时间复杂度和空间复杂度。
  4. 代码与复盘：贴出代码，并写下容易出错的地方。
写题解不是为了展示自己一次就做对，而是把思考过程留下来，帮助未来的自己和其他同学。
